# 2026-05-06 — Тематические кластеры и минимальная таксономия глаголов

## Lab note

**Дата:** 2026-05-06.

**Задача.** Активировать вторую ось L2-агрегации в метаграфе и сделать
labels у L2-метавершин содержательными для дипломной защиты. Дополнительно
ввести минимальную rule-based таксономию глаголов как третью L2-стратегию,
чтобы оси аггрегации (параграф / сущность / предикат) были видны на
небольших примерах.

**Гипотезы.**

1. Если включить вторую L2-стратегию рядом с параграфной, то правило
   `topic_overlap_v0` впервые даёт непустой результат: одни и те же
   L1-клаузы попадают и в параграф, и в кластер по общим леммам, поэтому
   фрагменты L2 пересекаются.
2. «Самая частая значимая лемма во фрагменте» (после исключения
   стоп-UPOS) — достаточно стабильный детерминированный label, чтобы не
   изобретать новых эвристик; для предикативных классов имя класса само
   является содержательной меткой.
3. Ручной YAML-словарь `lemma → class` объёмом ~80 русских лемм по 8
   классам — минимальный жизнеспособный способ ввести таксономию глаголов
   без нарушения rule-based инварианта (CLAUDE.md §3, пункт «нельзя
   строить ядро системы вокруг нейросетей»).

**Что изменено.**

  (через `git mv`, история сохранена). Правило: `coref_cluster_v0` →
  `entity_cluster_v0`. Тип L2-метавершины: `coref_cluster` →
  `entity_cluster`. Имя путало с настоящей кореференцией, которой

**Ограничения.**

- Словарь предикативных классов крошечный (~80 лемм, 8 классов).
  Многие распространённые глаголы пока не покрыты; расширение —
  итеративная ручная работа.
- Холархическая визуализация показывает дополнительные L2-родителей
  через `contains`-рёбра, но layout продолжает использовать
  compound-nodes с одним основным parent. Полный переход на explicit
  containment требует другого layout-движка и отложен.
- Generic multi-round runner для `L_k → L_{k+1}` не реализован.
  Решение: пересмотреть, когда стратегий станет ≥4 (вероятный кандидат —
  кластеризация по протагонисту через анафору + entity_cluster).

## Thesis paragraph

Переход от плоского семантического графа к иерархической метаграфовой
модели в данном проекте реализован как последовательность правил
агрегации, каждое из которых детерминированно превращает множество
элементов уровня k в метавершину уровня k+1. На первом уровне (L1)
каждая клауза, выделенная rule-based анализатором по дереву UD-разбора,
сжимается в метавершину с типом `clause:{clause_type}` и фрагментом,
содержащим её узлы и рёбра; параллельно строится L1-метаребро
`shared_entity` для каждой пары клауз, разделяющих лемму значимого
концепта. На втором уровне (L2) реализованы три ортогональные оси
агрегации: параграфная (`paragraph_clauses_v0`), тематическая
(`entity_cluster_v0`, как connected components графа `shared_entity`)
и предикативная (`predicate_class_cluster_v0`, как группировка клауз по
семантическим классам глаголов из ручного словаря). Эти оси не
конкурируют, а сосуществуют: одна L1-клауза одновременно принадлежит
своему параграфу, своему тематическому кластеру (если он образовался
по общим сущностям) и одному или нескольким классам предикатов. Такая
организация соответствует холархическому подходу к языковым моделям —
один и тот же фрагмент рассматривается с нескольких ракурсов
(стереотипов), а не привязывается к единственному «родительскому» узлу.
Холархия делает правило `topic_overlap_v0`, которое строит L2-метарёбра
между пересекающимися фрагментами, не вырожденным: при единственной
партиционирующей стратегии (только параграф) пересечения отсутствовали
по построению. С точки зрения объяснимости (CLAUDE.md §7.4, §10) каждая
из трёх стратегий имеет явное rule-based основание: параграф —
структурное свойство текста, тематический кластер — транзитивное
замыкание лемматической общности, предикативный класс — соответствие
глагола ручному таксономическому словарю. Последний пункт намеренно
ограничен ручной разметкой, без mining-а из корпуса и без векторной
кластеризации, чтобы сохранить инвариант объяснимого преобразования
текста и не превратить ядро системы в чёрный ящик.
